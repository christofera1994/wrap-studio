## Packages
framer-motion | Complex animations for the "cinematic" feel

tailwind-merge | Utility for merging Tailwind classes efficiently
lucide-react | Icons (already in base, but listing for completeness)

## Notes
The app requires a Supabase project for the backend logic as per the schema.
Images will be sourced from Unsplash for the demo, but in production would come from Supabase Storage.
The "Ferrari Red" color code is #D50000.
The background will use a custom canvas implementation for performance.
